# Lany Avatar

先读 [Style DNA](references/style-dna.md)，再看 `assets/lany-avatar-reference.png`。当前头像是已有身份资产；普通调用默认做清晰度、构图或尺寸改进。只有用户明确提出重塑形象时才重新探索身份。

## 输入与判断

- 用户本次确认的新头像或本人照片优先于内置参考；观察实际可见的脸型、发型、护目镜、耳机和服装。新照片用于真实身份还原时，以照片为准，不把旧插画特征强加到真人身上。
- 如果用户提供其他创作者参考，只提炼线条、留白、色彩比例、构图等设计规律；不复制其脸、独特构图或文字。
- 头像用于小尺寸圆形裁切：保留头肩轮廓，一个品牌主色、少量可辨识特征。不要把名称、口号和场景文字塞进头像。

## 产出

1. 在 `<项目根>/lany-assets/lany-avatar/<slug>/` 保存 `prompts/avatar.md`、`style-dna.md` 和最终头像。若已存在，使用 `avatar-v2.png` 等版本名；保留原版。
2. 使用提供的身份参考生成精致像素插画头像，默认正方形。明确要求其他媒介或真人形象时按用户要求。
3. 核对人物身份、色彩与媒介；检查完整方图及模拟圆形裁切，缩到 48px 和 96px 时仍能识别。文字、饰品和面部不可凭空增加。
4. 报告参考图、最终文件、Style DNA 和核对结果。当前工具若只能返回预览，不宣称文件已保存。

头像生成属于图片任务，使用可用的生图工具；不得拿代码绘制的占位图冒充最终头像。后续 Banner、封面、正文插图继续以用户确认的最终头像为身份参考。
