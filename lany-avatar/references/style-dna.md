# Lany 小生 Style DNA（当前已确认版本）

身份参考：`../assets/lany-avatar-reference.png`。这是小尺寸像素头像，实际可见的是少年感窄脸、黑色短发、头顶护目镜、颈部银灰耳机和黑色上衣。参考图未清楚展示的胸前字标、身体和鞋子，不作为头像的必填特征。

- 人物媒介：精致像素插画，可见像素边缘与块面阴影；保持成熟比例，避免平滑 3D、黏土、写真或陌生动漫脸。
- 品牌色：荧光黄绿 `#D8FF00`；深色 `#0A0A0A` 与石墨灰；少量暖白 `#F3F3ED`。蓝色只在原角色细节确有依据时出现。
- 识别点：相同人物轮廓、发型、护目镜与耳机；其他资产可变化动作与场景，不能重造身份。
- 构图语言：非对称编辑排版、留白、细线网格、受控几何形与清晰信息层级。这个规则用于 Banner、封面、插图、信息图与图表，但头像本身应更简洁。

更新规则：用户确认新头像后，以新图更新本文件和各 Lany 技能的角色参考；在确认前保留当前资产，不把试验图自动升级为品牌真源。
