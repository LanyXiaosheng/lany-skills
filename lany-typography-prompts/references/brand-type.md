# Lany 文字视觉基准

## 品牌默认

Lany 小生的画面以墨黑 `#0A0A0A`、石墨灰、暖白 `#F3F3ED` 和荧光黄绿 `#D8FF00` 为主。标题与人物的身份要稳定，但人物的像素媒介不等于标题必须是游戏像素字。标题默认采用现代几何无衬线：笔画中粗、字形端正略紧、清晰转角、适度紧凑的字距与明确的行距。标题最多两行，辅助文案退后一层。

| 文字任务 | 优先字形 | 可用字效 |
| --- | --- | --- |
| X 长文封面主标题 | 稳定几何无衬线，厚度足以缩图阅读 | 荧光黄绿局部划线或受控切面 |
| 主页 Banner 名称与定位 | 名称中粗，定位文字常规字重 | 细线网格或一个局部色块 |
| 信息图节点与数据标签 | 常规无衬线，字面开放、间距宽松 | 无字效，靠层级与对比阅读 |
| 小生身份短标记 | 克制方块或像素边缘，字符很短 | 少量像素感，仅作辅助 |

用户明确指定其他文字风格时，先保留逐字文案、画幅、品牌身份和可读性，再调整字形与材质。霓虹、重金属、液态、爆破、复杂毛笔和大面积 3D 等是实验方向，不自动带入日常 Lany 视觉。第三方参考只拆解笔画、结构和材质规律，不复刻其独有标题造型。

来源启发：用户提供的 Adrian Punk《2026 文字类提示词设计指南》上、下册。两册列举了多种中文字形与字效名称；本规则只提炼描述维度与选择原则，不复制其图片和完整提示词。
