# 文字视觉提示词结构

先确定实际文案，再填下面与任务相关的字段。每项写可观察的视觉特征，不堆砌风格名。

- **独立字图**：文字就是画面主体；列出完整的主标题、副标题或明确写“无”。
- **封面 / Banner 内嵌文字**：只描述指定文字模块的字形与位置。完整文案、人物、背景及场景由调用它的封面 / Banner 任务决定，不擅自写“整张画面仅显示这些字”。

```text
用途：{封面标题 / Banner 名称 / 信息图标签 / 独立字图}，画幅 {比例或尺寸}。
文字模块：主标题逐字为“{逐字中文}”；副标题为“{逐字中文或无}”。简体中文，标点与字序必须正确。独立字图不添加其他字；内嵌模块不限制父画面的其他已确认文字。
字形：{无衬线/其他已选方向}；笔画 {粗细}；字面 {宽窄}；结构 {紧凑/舒展}；边缘 {几何/圆角/切面}；字距与行距 {具体要求}。
字效：{无，或唯一一项可见效果}；材质/纹理 {平面印刷、轻微颗粒等}。效果不能破坏笔画识别。
配色：主字 {暖白或其他明确颜色}；关键字/下划线 {#D8FF00}；背景 {#0A0A0A/白色/用户指定}。
版式：主标题位于 {安全区位置}，最多 {行数} 行，辅助文字层级更低；保留头像、角色或图表所需空位。
避免：乱码、错别字、多余英文、随机符号、难辨认的字形、过度发光、PPT 艺术字和未经要求的第二主色。
```

例如“赛博小晚”的 Lany 常规封面标题，可以描述为：暖白、厚实但不过分膨胀的几何无衬线汉字，字面比例一致、字距略紧、两行以内，底部一段短而明确的 `#D8FF00` 信号线；哑光黑底，文字远看完整可辨。这个例子说明描述方法，不把该标题固定给其他文章。
