# Lany Typography Prompts

先读 [品牌字形规则](references/brand-type.md)。该技能处理图中的文字视觉：字形、笔画、间距、边缘、材质、色彩和排版层级。文章写作仍由写作任务本身处理；完整封面与 Banner 分别由 `$lany-cover` 和 `$lany-banner` 负责。

## 输入与选择

1. 明确要显示的**逐字文案**、语言、用途、画幅和背景。用户只给文章时，可提议一个短标题并标明是待确认文案；没有准确文案就不要声称完成最终字图。
2. 从品牌字形规则中选一种主方向，说明为何适合这段文案与载体。默认是现代几何无衬线和克制的编辑排版；用户明确要实验风格时，可探索其他字体或字效，但不把参考图的独特字形直接复制。作为 `$lany-cover` 或 `$lany-banner` 的组成部分时，继承其整体配色、媒介和版式约束；只有用户明确要求不同风格时才覆盖默认约束，并指出视觉体系发生了什么变化。
3. 按 [提示词结构](references/prompt-blueprint.md) 写出可直接用于生图的提示词。区分独立字图和嵌入完整封面/Banner 的文字模块；后者由父任务决定完整文案、主体与场景。本技能写清笔画粗细、字面比例、结构松紧、字距、边缘、材质、色彩、背景、标题安全区及禁用项。避免“高级”“有设计感”之类不能指导画面的空词。
4. 一张图保留一套字形主逻辑和一个可选字效。小字号说明文字优先可读性，不套用夸张标题字效。像素小生是人物媒介，并不要求主标题也使用像素字体。

## 交付与验收

- 只要提示词时，直接交付可复制的提示词；作为项目资产时另存到 `<项目根>/lany-assets/lany-typography-prompts/<slug>/prompts/type.md`。项目根优先使用用户指定目录，其次是明确的文章文件所在目录，否则用当前可写工作目录；多个候选文章时先确认目标。slug 取明确文章名或标题的简短安全文件名，不从无关目录猜测。
- 用户要求实际出图时再调用可用生图工具，将当前调用明确返回的图片保存为 `type-source.png`，校正后另存 `type.png`；原有文件使用 `-v2` 等后缀，不覆盖。文字需要可编辑修正时同时保存 `type.svg` 或 `type.html`。
- 逐字核对简体中文、标点和字序；核对最终像素尺寸、裁切边界、远看识别度、手机缩图、标题层级与安全区。生图工具若写错字，优先在可编辑 SVG/HTML 或设计文件里用真实字体重排，重新导出并复查；不要把错字图当成最终品。
- 报告所用文案、字形方向、提示词路径与图片路径（如有）。没有安装的字体不得称为已使用字体；商业发布前核对实际字体素材的许可。
