# 内置生图可靠性

本机无法稳定直连 `chatgpt.com`，内置生图依赖本地代理。参考图编辑比纯生成更容易暴露链路中断或请求超时。

## 预检

调用参考图生图前运行 `python3 scripts/imagegen_preflight.py`。预检失败时先恢复代理。若 Clash Verge 已安装但 `127.0.0.1:7897` 未监听，可运行 `open -a "Clash Verge"`，等待端口恢复后再生成。

## 请求控制

- 默认只传 `assets/lany-avatar-reference.png` 一张参考图；用户本次确认了新头像时，以本次头像为唯一身份参考。
- 不把文章全文、风格文档或重复禁用项粘进图片提示词；提示词目标为约 500—1200 中文字。
- 需要多角度时才添加角色设定板，并先生成轻量副本。
- 每张图片单独调用一次。成功后立刻复制到项目目录。

## 失败分级

1. `network error`、`connection failed` 或 `error sending request`：运行预检，确认代理端口与远端握手，再重试一次。
2. 初次调用使用 384px 参考。第一次失败后先预检，预检成功再重试一次；再次失败后生成 256px 参考，把提示词缩到只保留内容、身份、颜色、媒介和禁用项，做最后一次调用。
3. 每张总计最多三次调用；第三次仍失败时停止，报告网络状态和提示词文件，不连续盲重试。
4. 不得为了绕过失败去掉身份参考图，否则会造成陌生脸和媒介漂移。
5. 纯生成成功而参考图编辑失败时，判定为编辑上传链路问题，不改写视觉风格。

CLI/API 兜底需要单独的 `OPENAI_API_KEY`，只有用户明确选择该路径时才使用。
