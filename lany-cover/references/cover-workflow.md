# 封面提炼与提示词

## 内容提炼

从完整材料中只保留：短主标题、一句可选副标题、一个主体动作、一个物理关系、受众与用途。

中文主标题优先控制在 6—14 个字并最多两行。不要把文章摘要堆进画面。若原题很长，主标题承担传播，完整题意进入一行小页眉或副标题。

## 紧凑提示词骨架

不要逐段粘贴品牌文档。将下面字段压缩成一份约 500—1200 中文字的完整提示词：

```text
用途与比例：一张 {平台} 封面，{比例}。
内容：主标题逐字为“{标题}”；副标题逐字为“{副标题或无}”。
主体关系：小生在 {位置和动作}，一条 #D8FF00 连续路径连接 {起点、节点、结果}。
构图：{针对比例的非对称布局与安全区}。
身份：使用用户确认头像中的同一像素小生，优先保持头像可见的脸型、发型、护目镜、耳机、服装轮廓和像素边缘；头像中不可见的细节不强行补齐。
视觉：#0A0A0A 与石墨灰背景，#D8FF00 为唯一大面积强调色，少量 #F3F3ED；采用咨询报告式高精细编辑排版，一个核心视觉隐喻，大面积呼吸空间，不做流程 PPT。
禁止：平滑 3D、写实、日漫重绘、陌生脸、闲鱼黄大色块、蓝紫粉渐变、玻璃、HUD、PPT、随机文字、水印、二维码。
```

## X 画幅

- X 长文或帖子封面：`5:2`，标题和人物分别占据清晰视觉区。
- X 主页背景由 `$lany-banner` 处理；不要把文章封面直接裁成主页 Banner。
- 不用裁切一张图去兼容多个比例；每个比例独立构图。
