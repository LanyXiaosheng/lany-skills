# Lany Infographics

读 [信息图规则](references/diagram-rules.md)。输入可以是文章、段落、工具流程、行业事件或一组实体关系；也可在选题阶段先画出事件背景与影响路径。先确定读者看完应理解的一件事，再决定使用流程、关系、时间线、对比或概念图。不要把原文逐段塞进卡片。

## 生成

1. 读取完整材料并抽取节点、关系、方向和证据。仅用材料支持的内容；必要假设标注为假设。用户给出源链接时保留来源。
2. 写一句图的结论与一份节点清单。通常每张图只解释一个关系；复杂主题可拆成多张，但不要为了数量凑图。
3. 用可编辑的 SVG 或固定尺寸 HTML/CSS 制作精确中文、线条和层级，再导出 PNG。需要氛围插画时可使用生图，但关键文字和拓扑关系以可编辑源文件为准。
4. 默认 X 长文配图为 16:9；用户指定比例优先。输出到 `<项目根>/lany-assets/lany-infographics/<slug>/`，保留源文件和最终图片，同名使用版本后缀。
5. 在文章中使用时，把图片放到它所解释的段落之后，并在下一段继续论述；不把多张图统一堆到文末。用户明确要求写入 Markdown 时，先备份，再用相对路径插入并检查文件可读。

交付时说明核心关系、来源、文件路径及建议插入锚点。不得将未验证的占位数据或随机图标伪装成信息图。
