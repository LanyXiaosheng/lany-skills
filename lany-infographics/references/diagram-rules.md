# Lany 信息图规则

## 视觉身份

- 主色：`#D8FF00` 用于唯一关键路径或判断节点；背景按用途选 `#0A0A0A` 深色或干净白色。石墨灰与 `#F3F3ED` 支撑层级；不要引入第二种抢眼主色。
- 排版：现代几何无衬线、非对称编辑构图、明确的标题与图例。细线网格或几何切面是秩序，不是装饰堆积。
- 小生人物：不是每张图都必须出现；如果人物承担实际动作，使用 `../assets/lany-avatar-reference.png` 的像素身份。纯技术机制图可只用品牌色和版式建立识别。

## 选图形

| 要回答的问题 | 推荐结构 |
| --- | --- |
| 先后怎么发生？ | 流程或时间线，箭头方向唯一 |
| 谁影响谁？ | 关系图，节点少且边有含义 |
| 两种方案如何取舍？ | 对比图，同一维度对齐 |
| 一个概念由什么组成？ | 层级图或分解图 |

标签必须清楚、可读，避免无意义图标和未定义缩写。先检查拓扑和内容，再检查风格。小屏预览时核心结论仍能看懂；多余节点应删减或拆图。
