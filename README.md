# lany-skills

Codex / Agent skills：Lany 与 Punk 两套视觉技能。

## Lany

Lany 小生的个人视觉 IP 以当前像素头像为人物身份基准，各资产复用黑色、`#D8FF00`、暖白和像素人物的视觉语言。

| Skill | 用途 |
| --- | --- |
| `$lany-avatar` | 精修头像并保存 Style DNA |
| `$lany-banner` | X 主页横幅和安全区预览 |
| `$lany-cover` | X 长文、帖子与公众号封面 |
| `$lany-ip-article-illustrations` | 有明确正文锚点的小生插画 |
| `$lany-infographics` | 流程、关系、概念和对比信息图 |
| `$lany-data-charts` | 真实数据图表、动态数据画面与简报 |
| `$lany-typography-prompts` | 中文标题字形与字效的可复用生图提示词 |

例如：`使用 $lany-banner，以我当前头像为身份参考，制作 X 主页横幅。`

材料分析、各 Skill 的边界和统一验收标准见 [个人视觉 IP 体系](VISUAL-IP-SYSTEM.md)。仓库目录本身可供阅读和维护；要在 Codex 中使用 `$` 调用，需要把各 Skill 目录安装到 Codex 技能目录。

## Punk

- **punk-avatar** — 头像 / 纸艺肖像
- **punk-cover** — 文章与社交封面
- **punk-ip-article-illustrations** — 个人 IP 正文插图
- **punk-xhs-cards** — 小红书知识卡片
