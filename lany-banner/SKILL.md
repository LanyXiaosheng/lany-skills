# Lany Banner

先读 [品牌与版式规则](references/banner-layout.md)，以 `assets/lany-avatar-reference.png` 或用户本次确认的新头像为身份参考。Banner 是主页入口：读者应在几秒内看出名称、内容方向和视觉气质。已有头像不重新设计。

## 制作

1. 从用户当前简介、已确认定位或本次文案提炼一句核心信息；没有依据时只放名称和已知内容方向，并明确待确认文案，不虚构履历或成绩。
2. 默认 X 主页画布 `1500×500`。头像覆盖区域和移动端裁切以当前页面预览为准；不把名字、脸或核心语句放在左下遮挡区与两侧裁切边缘。其他平台按其当前画幅单独构图。
3. 选一个主关系：小生与内容主题，或小生与一个代表工作方法的物件。标题、角色和 `#D8FF00` 信号线清楚分区，留出呼吸空间。禁止把文章封面简单裁成 Banner。
4. 在 `<项目根>/lany-assets/lany-banner/<slug>/` 保存 `prompts/banner.md`、最终 `banner.png` 和必要的源图；同名存在时使用 `-v2`。记录所用文案与排版决定。
5. 验证尺寸、文字准确性、人物身份和像素媒介。把头像叠加到实际主页截图或等比例预览，检查桌面与窄屏裁切；报告仍需人工确认的显示差异。

当用户只要方案时交付可执行布局和文案，不生成占位图；当用户要图时实际调用生图工具并保存结果。不要自动上传到 X。
