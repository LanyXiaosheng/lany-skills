# Lany Banner 版式规则

## 当前品牌

- 身份：`../assets/lany-avatar-reference.png` 中的像素小生，黑发、头顶护目镜、颈挂耳机、黑衣。可变动作，不换脸、不改成平滑 3D。
- 颜色：哑光黑 `#0A0A0A`、石墨灰、暖白 `#F3F3ED`；`#D8FF00` 为唯一大面积高饱和强调色。第三方品牌色只作小标签。
- 设计：非对称编辑排版、现代几何无衬线、细线网格、少量几何切面、清晰的信息层级。一个核心主体关系即可。

## X 默认画布与检查

- 默认尺寸 `1500×500`，比例 3:1；这是当前工作流约定，发布前以 X 页面实际显示复核。
- 左下约 `340×210` 作为头像遮挡预留区，不放不可丢失的文字或人物脸。重要元素还要远离最左、最右裁切边缘；不同设备需看预览。
- 文案优先：名称 / 一句话内容方向 / 可选关键词。不要把 Banner 当个人简历，不写未核实的资历、粉丝数或承诺。
- 主页测试：头像与 Banner 是否像同一品牌；三秒内能否看懂；窄屏上文字、脸、行动信息是否仍完整。
