# Lany 数据图表规则

## 真实性优先

- 把数值、时间、单位、分母和来源视为输入契约。金额注明币种，比例说明基数，增长说明起止点。
- 缺失值与零不同；不自动填 0。不同口径不能未经说明直接并列。
- 轴起点、截断、对数刻度、归一化或累计值会改变读法，用到时标清楚。不要让装饰盖过标签和数据。
- 计算值与源数据一起保存，读者能从源表复算核心结论。

## 品牌表达

- 深色背景 `#0A0A0A` 或干净白底；`#D8FF00` 用来强调关键系列或结果，其他系列用不同明度的石墨灰与暖白 `#F3F3ED`，必要时使用形状、线型和直接标签辅助区分。
- 标题是一句有证据的发现，不是“数据图表”。人物参考 `../assets/lany-avatar-reference.png` 可用于报告封面或旁注，不能遮挡数据。
- 保持现代编辑排版与充足留白。参考图只借用字体、网格与颜色逻辑，不能复制第三方图表的独特表达。

## 三种交付

- 文章配图：一个结论、一张图、一句解释和来源；在正文相关段落后出现。
- 视频数据画面：标题与关键数字的入场应克制；保持适合静音观看的清晰标签。
- 简报/报告：多个图表围绕同一问题组成叙事，封面摘要、数据范围、口径、图表与结论相互可追溯。
