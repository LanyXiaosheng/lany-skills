# Lany Data Charts

读 [数据与图表规则](references/data-rules.md)。根据用途选择单图、视频数据画面或报告；不要为了视觉效果改变数值、截断比较关系或省略必要单位。

## 工作方式

1. 读取用户给的数据、来源、时间范围、单位与口径；识别缺失值、重复项和不可直接比较的分母。若用户只给主题没有数据，先说明缺哪类数据；可以做明确标为“示意”的样稿，不能当真实结论交付。
2. 写下图要回答的问题，再依据数据结构选图：时间变化用折线；类别比较用横向条形或柱形；比例用 100% 堆叠等合适形式；少量关键数用数字卡。无需预先指定图型。
3. 用可复核的代码、SVG 或 HTML 绘图并保留原始输入和计算结果。动态画面可基于 HTML 动画，但静态帧也必须能读懂。报告模式才组织标题、核心结论、KPI、图表、旁注和数据来源。
4. 默认文章图 16:9；其他比例由用户指定。输出到 `<项目根>/lany-assets/lany-data-charts/<slug>/`，保存源数据或数据引用、可编辑源文件、最终 PNG；动态内容另交付可预览 HTML 或用户要求的格式。
5. 人工核对至少三个数据点、轴、单位、排序、百分比/增长率计算和图例；再缩小到手机宽度检查文字。引用真实外部数据时在图内或图旁标来源与日期。

写入文章时把图放到首次论证该数据的段落之后，并让后文解释结论；用户要求直接写入 Markdown 时先备份并使用相对路径。不将所有图表堆到文末。交付时说明来源、口径、文件和仍未验证的部分。
